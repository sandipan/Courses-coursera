Basic Functions:¶

rnorm( ) function generates a vector of random normal variables, with first argument 'n' the sample size

In [1]:
x = rnorm(50)
y = x + rnorm(50, mean = 50, sd = .1)

In the above code snippet,
'x' is a vector of 50 random variables
'y' is a vector of 50 random variables that are distributed around the point/mean 50
