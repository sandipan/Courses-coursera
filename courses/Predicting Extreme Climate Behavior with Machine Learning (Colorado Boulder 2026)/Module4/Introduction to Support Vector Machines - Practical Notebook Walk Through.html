Model Optimization¶

Optimizing the model using GridSearchCV for Accuracy Metric¶

Optimizing a Support Vector Machine (SVM) model using GridSearchCV for the accuracy metric involves systematically exploring a range of hyperparameters to find the combination that yields the highest accuracy on your dataset. Here’s a step-by-step breakdown of what this entails:

  1. Define the Hyperparameter Grid:

For SVMs, common hyperparameters to tune include the C parameter (regularization), gamma (kernel coefficient for ‘rbf’, ‘poly’, and ‘sigmoid’ kernels), and the kernel type itself (linear, poly, rbf, sigmoid). You need to create a grid of values for these hyperparameters to test. For example:

C: [0.1, 1, 10, 100]

gamma: [0.001, 0.01, 0.1, 1]

kernel: [‘linear’, ‘rbf’]

  1. Use the GridSearchCV class from scikit-learn to perform an exhaustive search over the specified hyperparameter grid. You also specify the performance metric to optimize, which in this case is accuracy.

  2. Fit the Model: Train the model using the fit method of GridSearchCV, which will evaluate all possible combinations of hyperparameters using cross-validation.

  3. Select the Best Model: GridSearchCV will determine the best combination of hyperparameters based on the accuracy metric. The best model is the one that achieved the highest average accuracy across the cross-validation folds

  4. Evaluate the Best Model: After identifying the best parameters, you can use this model to make predictions on your test data and evaluate its performance.

All in all, optimizing an SVM model using GridSearchCV for accuracy involves defining a range of hyperparameters to explore, setting up the grid search with accuracy as the scoring metric, fitting the model, and selecting the best-performing hyperparameter combination based on the accuracy achieved through cross-validation.

# Implementing SVM with GridSearchCV for hyperparameter tuning of linear, rbf and poly kernels

params_grid = [{'C': [0.1, 0.5, 1, 5, 10], 'kernel': ['linear']},
               {'C': [0.1, 0.5, 1, 5, 10], 'kernel': ['rbf']},
               {'C': [0.1, 0.5, 1, 5, 10], 'kernel': ['poly'], 'degree': [2, 3, 4]}]

classifier = SVC()
grid_search = GridSearchCV(estimator = classifier,
                           param_grid = params_grid,
                           scoring = 'accuracy', # accuracy is used as scoring metric
                           cv = 10,
                           n_jobs = -1)

grid_search.fit(X_train, y_train)

# Displaying the best parameters
best_accuracy = grid_search.best_score_
best_parameters = grid_search.best_params_
print('Best Accuracy:', best_accuracy)
print('Best Parameters:', best_parameters)
