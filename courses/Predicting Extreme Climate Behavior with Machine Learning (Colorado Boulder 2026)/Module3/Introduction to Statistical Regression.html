Exercise 1: Noisy Lines¶

The formula for a line is usually written as $$y = b+mx$$

This defines the relationship between $x$ and $y$, by multiplying $x$ by the slope $m$ and adding the intercept $b$.

Since we can call the slope and intercept anything we want, we'll use the notation found in your book, $$y = \alpha + \beta x$$

** Part A **: There is nothing random in the equation above. Write a function that plots this equation for $\alpha=0.5$ and $\beta=1$, on the domain $x \in [0,5]$.

Normally, when we plot lines, for a given independent variable $x$, there is a fixed $y$. But in real-world scenarios, we don't just get $y$ back. We often get $y$ back with noise.

Write a function that takes in values of $x$, $\alpha$, and $\beta$ below, and returns $$ y = \alpha + \beta x + \epsilon$$ where $\epsilon$ is drawn from a Normal distribution with mean of $0$ and variance of $\sigma^2$. Be sure to allow your function to take the variance as an input, too.

In [3]:
def y_noisy(a,b,x,var):
    noise = np.random.normal(0, var, len(x))
    return a+x*b+noise

Exercise 2: Repeat-o-fit¶

Part A: Code up a function that takes in sets of matched x and y values and returns the linear regression parameters $\hat{\alpha}$ and $\hat{\beta}$.

In [7]:
def regression(x,y):
    xbar = x.mean()
    ybar = y.mean()
    numerator = np.array((x - xbar)*(y - ybar)).sum()
    denominator = np.array((x - xbar)*(x- xbar)).sum()
    beta = numerator/denominator
    alpha = ybar - beta*xbar
    yhat = alpha + beta*x
    return alpha,beta,yhat
